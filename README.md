# WinterBorn Web

Official website for WinterBorn AB.

## Stack
- Next.js 16.3.6
- React 19
- TypeScript
- Tailwind CSS 4.3.3

## Local development
```powershell
npm install
npm run dev
```

## Verification
```powershell
npm test
npm run lint
npm run build
```

## Brand status
The current site uses a text-only `WinterBorn` wordmark. The final visual identity/logo will replace it later without changing the site structure.
